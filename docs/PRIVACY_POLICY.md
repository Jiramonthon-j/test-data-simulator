# นโยบายความเป็นส่วนตัว — Intelligent Test Data Simulator

เอกสารนี้อธิบายว่าระบบเก็บข้อมูลอะไรบ้าง เพื่อวัตถุประสงค์อะไร เก็บไว้ที่ไหน และใครเข้าถึงได้บ้าง สำหรับผู้ใช้งานภายในทีมที่ลงทะเบียนใช้งานระบบนี้

---

## ข้อมูลที่เก็บ

| ข้อมูล | เก็บไว้ที่ | หมายเหตุ |
|---|---|---|
| ชื่อผู้ใช้งาน (username) | แท็บ `Users` | ใช้ระบุตัวตนตอนเข้าสู่ระบบ |
| รหัสผ่าน | แท็บ `Users` | เก็บเป็น salted SHA-256 hash เท่านั้น **ไม่เก็บเป็นตัวอักษรธรรมดา** ไม่มีใครในระบบ (รวมถึงผู้ดูแลระบบ) เห็นรหัสผ่านจริงของผู้ใช้ได้ |
| อีเมล | แท็บ `Users` | ใช้ส่งรหัสยืนยัน (OTP) เวลากด "ลืมรหัสผ่าน" และแจ้งเตือนความปลอดภัยเมื่อบัญชีถูกล็อกจากการเข้าสู่ระบบผิดพลาดหลายครั้งติดต่อกันเท่านั้น |
| ชื่อ-นามสกุลจริง | แท็บ `Users` | ใช้ให้ผู้ดูแลระบบ (Super_Admin) ระบุตัวตนที่แท้จริงของผู้ใช้แต่ละบัญชีได้ง่ายกว่าดูแค่ username |
| แผนก/ทีมที่สังกัด | แท็บ `Users` | ใช้ให้ผู้ดูแลระบบเห็นภาพรวมว่าทีม/แผนกใดใช้งานระบบนี้บ้าง เพื่อความสะดวกในการติดตามการใช้งาน |
| บทบาท (role) | แท็บ `Users` | ใช้กำหนดสิทธิ์การใช้งานภายในระบบ |
| ประวัติการใช้งาน (เวลา, ชื่อผู้ใช้, ประเภทกิจกรรม) | แท็บ `ActivityLogs` | เช่น เวลาเข้าสู่ระบบ/ออกจากระบบ, เวลาสร้างข้อมูลทดสอบ, เวลาบันทึกข้อมูลลงฐานข้อมูล — ใช้ตรวจสอบความปลอดภัยและแก้ปัญหาย้อนหลังเท่านั้น |
| Prompt/เงื่อนไขที่ใช้สร้างข้อมูลทดสอบ | แท็บ `SavedPrompts`, `GeneratedPromptLogs` | เนื้อหาที่ผู้ใช้พิมพ์เพื่อสั่งสร้างข้อมูลทดสอบ รวมถึงรูป Schema/ER Diagram ที่แนบมา (ถ้ามี) |

## วัตถุประสงค์การเก็บข้อมูล

ระบบเก็บข้อมูลข้างต้นเพื่อ (1) ยืนยันตัวตนและควบคุมสิทธิ์การเข้าใช้งาน (2) กู้คืนรหัสผ่านให้เจ้าของบัญชีตัวจริงเท่านั้นผ่าน OTP ทางอีเมล (3) ตรวจสอบและป้องกันการใช้งานที่ผิดปกติ เช่น ความพยายามเดารหัสผ่าน (4) แก้ไขปัญหาการใช้งานย้อนหลังเมื่อจำเป็น **ไม่มีการนำข้อมูลไปใช้เพื่อการตลาด โฆษณา หรือส่งต่อให้บุคคล/องค์กรภายนอกใดๆ**

## สถานที่จัดเก็บและการควบคุมสิทธิ์เข้าถึง

ข้อมูลทั้งหมดเก็บอยู่ใน Google Sheet เดียว ซึ่งเข้าถึงได้เฉพาะบุคคลที่เจ้าของสเปรดชีตแชร์สิทธิ์ให้เท่านั้น (ควรจำกัดไว้เฉพาะผู้ดูแลระบบ/Super_Admin) การเข้าถึงข้อมูลผ่านหน้าเว็บถูกควบคุมด้วยระบบยืนยันตัวตน (username/password), session token ที่หมดอายุอัตโนมัติ, และการจำกัดสิทธิ์ตามบทบาท (role-based access control)

**ข้อจำกัดที่ควรทราบ:** ประวัติการใช้งาน (แท็บ `ActivityLogs`) เก็บอยู่บน Google Sheet ธรรมดา ไม่ใช่ระบบ log แบบ tamper-proof — ผู้ที่มีสิทธิ์แก้ไขสเปรดชีตนี้โดยตรง (นอกเหนือจากผ่านหน้าเว็บ) สามารถแก้ไขหรือลบแถวประวัติได้โดยไม่ทิ้งร่องรอย จึงควรจำกัดสิทธิ์แก้ไขสเปรดชีตนี้ให้แคบที่สุดเท่าที่จำเป็นเสมอ (ดูข้อ 1 ใน `IMPROVEMENT_CHECKLIST.md`)

## ระยะเวลาจัดเก็บ

ข้อมูลจะถูกเก็บไว้ตราบเท่าที่ยังใช้งานระบบอยู่ ผู้ดูแลระบบสามารถลบข้อมูลบางส่วนได้เอง เช่น ลบ prompt ที่ไม่ใช้แล้ว หรือลบชุดข้อมูลทดสอบเก่าที่ไม่จำเป็นผ่านหน้าเว็บ หากต้องการลบบัญชีผู้ใช้งานทั้งหมดออกจากระบบ สามารถแจ้งผู้ดูแลระบบ (Super_Admin) ให้ดำเนินการลบผ่านแผงจัดการผู้ใช้งานได้

## สิทธิ์ของเจ้าของข้อมูล

ผู้ใช้งานมีสิทธิ์ขอเข้าถึง แก้ไข หรือขอให้ลบข้อมูลส่วนตัวของตนเองได้ โดยกดปุ่ม "🗑️ ขอลบบัญชี" บนหน้า Dashboard เพื่อส่งคำขอแจ้งผู้ดูแลระบบ (Super_Admin) โดยตรง (ระบบจะไม่ลบบัญชีให้ทันทีอัตโนมัติ ต้องให้ Super_Admin เป็นผู้กดลบจริงผ่านแผงจัดการผู้ใช้งานเสมอ เพื่อป้องกันการกดพลาดหรือการใช้ปิดร่องรอยการกระทำผิด) หรือจะติดต่อผู้ดูแลระบบโดยตรงนอกระบบก็ได้เช่นกัน — **ข้อยกเว้น:** บัญชี Super Admin หลักของระบบ (ที่ระบบสร้างให้อัตโนมัติตอนติดตั้งครั้งแรก) ไม่สามารถส่งคำขอลบบัญชีตัวเองได้ เนื่องจากต้องมีอยู่เสมอเพื่อดูแลระบบและอนุมัติคำขอสมัคร Super Admin ใหม่ๆ

การสมัครสมาชิกด้วย role "Super Admin" ต้องได้รับการอนุมัติจาก Super Admin หลักของระบบก่อนเสมอ (บัญชีจะถูกสร้างไว้แต่ยังเข้าสู่ระบบไม่ได้จนกว่าจะได้รับอนุมัติ) เพื่อป้องกันไม่ให้ผู้ใดก็ได้เลือกสิทธิ์สูงสุดของระบบให้ตัวเองโดยไม่มีการตรวจสอบ

## ติดต่อสอบถาม

หากมีข้อสงสัยเกี่ยวกับการเก็บหรือใช้ข้อมูลส่วนตัวในระบบนี้ กรุณาติดต่อผู้ดูแลระบบของทีมที่ดูแลการ deploy ระบบนี้โดยตรง
