## 📌 Features

- **Two generation modes**
  - **Legacy Mode (AI)** — Gemini generates data from a DDL script and natural-language conditions.
  - **Rule-Based Mode (code)** — data is generated by code from rules in a `RuleTemplates` sheet (pattern, enum, number/date range, sequential, Thai citizen ID, Thai phone, email, etc.). No AI quota used and results are consistent every run.
- **Flexible table input** — accepts a standard SQL `CREATE TABLE` or a column listing copied straight from a DBeaver query result (column name, data type, max length, nullable), converted to standard DDL automatically.
- **Prompt template** — one click fills the conditions box with a structured template so users only edit the `[ ]` placeholders.
- **DDL Enforcement** — output columns, types, `NOT NULL` and `PRIMARY KEY` constraints are checked and corrected against the DDL by code.
- **Reference Column Lock** — reuse key values from a previously committed dataset so related tables stay consistent (Foreign Key testing).
- **Quality Gate** — data is validated (completeness, accuracy, constraint checks) before it reaches the dashboard.
- **SQL export** — `INSERT` statements for multiple SQL dialects.
- **Role-based access & session control** — QA Tester / Super Admin roles, idle auto-logout, request & approval workflow for missing rules.

## 🚀 Getting Started

1. Create a Google Sheet → **Extensions › Apps Script**, add the files in `apps-script/`.
2. Store your Gemini API key in **Script Properties** and run `setupSheet` once.
3. **Deploy › New deployment › Web app** (Execute as: Me, Access: Anyone) and copy the URL.
4. Set `BACKEND_URL` in `index.html` to that URL and publish with GitHub Pages.

Full details: [`docs/DEPLOY_GUIDE.md`](docs/DEPLOY_GUIDE.md)

2. **UI & API Automation:** feed generated data into automated tests (Playwright, Selenium).
3. **Boundary & Negative Testing:** create edge-case datasets for complex business logic.
